# Weekly reports

Generated every Monday by `.github/workflows/report.yml` from this sensor's
own telemetry. `latest.md` is always the most recent one.

Each report answers what changed, rather than repeating what the live
dashboards already show: which credentials are being sprayed this week, what
attackers did once they were inside, which ATT&CK techniques appeared, what
was captured, and what the honeypot refused to do.

Where a number is zero the report says so plainly. A quiet week on a public
address almost always means the sensor broke, not that the internet got
polite.
