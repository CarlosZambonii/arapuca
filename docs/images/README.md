# Screenshots

Dashboard screenshots go here, named `dashboard-overview.png` and
`dashboard-sessions.png`, once the sensor has collected enough to be worth
looking at.

They are deliberately absent rather than filled with invented images: a
dashboard of fabricated numbers would misrepresent what this project actually
produces, which is the one thing a portfolio piece must not do.

To take them: open the dashboards created by
`deploy/terraform/newrelic`, set the time picker to a window the sensor was
actually reporting in, and capture each page. Say which window it was in the
caption beside the image, because a dashboard is a picture of a period and an
unlabelled one invites the reader to assume the flattering reading. Blur or
crop anything that identifies the sensor's address.

One thing to avoid: the sensor was silent between 17:44 on 3 November and
16:05 on 4 November 2026, while a bad key sat in the agent's configuration.
A window spanning that shows a trough that is an outage rather than a quiet
night, so either keep the window clear of it or say so.
